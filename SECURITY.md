# Security Policy

## Supported Versions
Only the latest major version is currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within this project, please send an e-mail to the maintainers instead of opening an issue. All security vulnerabilities will be promptly addressed.
