# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-01-11

### Added
- Initial Telegram bot with aiogram v3
- Instagram reel/post video download support
- Twitter/X video download support
- Concurrent download queue with semaphore
- Browser cookie extraction for authenticated downloads
- State persistence with atomic writes
- File integrity verification
- Auto-cleanup of files after sending
- Docker containerization with non-root user
- Render deployment configuration
- GitHub Actions CI pipeline
- Unit tests with pytest
- Pre-commit hooks (ruff, black, mypy)
- Dependabot configuration
- Security policy
- MIT License

### Documentation
- README with badges and quick start
- README_BOT.md with deployment guide
- Architecture documentation
- SECURITY.md with best practices
